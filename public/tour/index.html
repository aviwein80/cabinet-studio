How to use this page

Each card is one topic. Press play, or use the chapters on the left. Subtitles are burned into the video, and an .srt file is under each one. The demo data (cabinets, materials, tools and cutting values) is made up for the tour; tool and feed values shown in the CAM videos are the app’s placeholders, not shop settings.
